# 🩺 Сурункали буйрак касаллиги (СБК / ХБП) ва КФТ ҳисобловчи Telegram Бот

Ушбу Telegram бот қондаги креатинин, беморнинг ёши ва вазни асосида **коптокчалар фильтрацияси тезлигини (КФТ / GFR)**, сийдикдаги альбумин ва креатинин миқдори асосида **альбумин-креатинин нисбатини (АКН / ACR)** ҳисоблаб беради ҳамда халқаро **KDIGO** клиник кўрсатмаларига асосан сурункали буйрак касаллигининг (СБК) даражаси ва хавф матрицасини аниқлайди.

---

## 🌟 Асосий Имкониятлари

1. **Коптокчалар фильтрацияси тезлиги (КФТ / GFR)**:
   - **Кокрофт-Голт (Cockcroft-Gault)** формуласи бўйича креатинин клиренси (ёш, вазн, жинс ва қон креатинини асосида).
   - Замонавий **CKD-EPI (2021)** формуласи бўйича eGFR.
   - **G1 – G5** босқичларини аниқлаш ва клиник изоҳ бериш.
   - Креатинин бирликлари: `мкмоль/л (µmol/L)` ва `мг/дл (mg/dL)`.

2. **Альбумин-креатинин нисбати (АКН / ACR)**:
   - Бир марталик сийдик таҳлилидаги альбумин ва креатинин нисбати.
   - **A1, A2 (микроальбуминурия), A3 (макроальбуминурия)** босқичларини аниқлаш.
   - Бирликлар: Альбумин (`мг/л`, `мг/дл`), Креатинин (`г/л`, `ммоль/л`, `мг/дл`).

3. **KDIGO бўйича Тўлиқ СБК Ҳисоботи ва Хавф Матрицаси**:
   - GFR ва Альбуминуриянинг кесишмасидан келиб чиққан ҳолда интеграл босқични аниқлаш (масалан: `G3aA2`).
   - 4 та тоифадаги хавф даражаси:
     - 🟩 **Паст хавф (Low risk)**
     - 🟨 **Ўртача ошган хавф (Moderate risk)**
     - 🟧 **Юқори хавф (High risk)**
     - 🟥 **Жуда юқори хавф (Very High risk)**
   - Шифокор кўриги, назорат частотаси ва клиник тавсиялар.

```

├── states.py           # FSM ҳолатлари

├── calculators.py      # Тиббий формулалар ва KDIGO матрицаси
├── handlers/
│   ├── __init__.py     # Роутерларни бирлаштириш
│   ├── common.py       # /start, /help, /cancel ва маълумотномалар
│   ├── full_calc.py    # Тўлиқ комплекс СБК текшируви
│   ├── gfr_calc.py     # Фақат КФТ ҳисоблаш
│   └── acr_calc.py     # Фақат АКН ҳисоблаш
├── test_calculators.py # Ҳисоб-китобларни текширувчи тест скрипти
├── requirements.txt    # Керакли кутубхоналар
├── .env                # Бот токени созламаси
└── README.md           # Қўлланма
```

## 🚀 Ўрнатиш ва Ишга Тушириш

### 1-Қадам: Telegram токен олиш
1. Telegram да [@BotFather](https://t.me/BotFather) ботига киринг.
2. `/newbot` буйруғини юборинг ва ботингизга ном беринг.
3. Сизга берилган `BOT_TOKEN` ни кўчириб олинг.

### 2-Қадам: Созламаларни киритиш
Лойиҳа папкасидаги `.env` файлини очинг ва олинган токенни киритинг:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
```

### 3-Қадам: Керакли кутубхоналарни ўрнатиш
Терминал ёки консолда:
```bash
python -m pip install -r requirements.txt
```

### 4-Қадам: Ботни ишга тушириш
```bash
python bot.py
```

## 🧪 Формулаларни Тест Қилиш

Ҳисоб-китоб алгоритмларининг тўғри ишлашини текшириш учун:

